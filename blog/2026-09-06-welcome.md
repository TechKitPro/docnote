# 欢迎来到 DocNote 🎉

DocNote 文档站正式上线了！

{/* truncate */}

这是一个基于 Docusaurus 构建的轻量级知识库，目标是把分散的笔记、教程和开发文档统一沉淀到一处，让知识可检索、可维护、可分享。

## 这里有什么

- **文档**：项目说明、快速开始、写作规范，见左侧「文档」导航。
- **博客**：站点更新日志、经验分享与使用心得。

## 如何参与

所有内容都托管在 GitHub 仓库 [TechKitPro/docnote](https://github.com/TechKitPro/docnote)，欢迎通过 Pull Request 提交改进。

Happy documenting!
